            사용자 프로젝트 외의 시스템 영역이나 민감 정보에 일체 접근하거나 파괴적인 작업을 수행하지 않도록 하네스를 물리적으로 격리합니다.
          

        


        
        

          

            

              🔒 1. Strict Root Directory Whitelist
            

            

              모든 파일 생성, 수정, 삭제 및 터미널 실행은 /Users/hhhk/dev 하위 경로로만 100% 한정됩니다. 외부 폴더 접근 시 즉시 차단됩니다.
            

          


          

            

              🚫 2. Anti-Path-Traversal Defense
            

            

              상대 경로(../)나 심볼릭 링크를 통해 상위 홈 디렉터리(`~/.ssh`, `~/.aws`, `/etc`)로 탈출하려는 모든 시도는 realpath() 검증 단계에서 예외 처리됩니다.
            

          


          

            

              🛡️ 3. Secret Shield (.gitignore 강제)

              ⚡ 4. Safe Command Whitelisting
            

            

              위험한 파괴적 커맨드(`rm -rf /`, `mkfs`, 임의의 `curl | sh`) 실행은 원천 봉쇄되며, `git`, `pnpm`, `flutter analyze` 등 검증된 개발 커맨드만 허용됩니다.
