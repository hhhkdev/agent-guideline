🔌 스킬 자동 수집 웹훅 (Webhook API)

외부 크롤러, GitHub Action, 웹 자동화 봇에서 아래 엔드포인트로 POST 요청을 보내면 스킬 마켓플레이스 및 가이드라인 저장소에 실시간 축적됩니다.

POST http://127.0.0.1:8765/api/skills/webhook
{
  "name": "my-crawled-skill",
  "category": "Frontend & API",
  "pros": "자동 스크래핑된 유용한 프롬프트/스킬",
  "cons": "커뮤니티 검증 대기 중",
  "verdict": "자동화로 수집된 최신 스킬"
}
💡 등록 즉시 04-skills-archive/[name]/SKILL.md 파일로 자동 생성됩니다.
