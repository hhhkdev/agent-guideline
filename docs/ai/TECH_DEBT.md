# 06. 기술 부채 및 로드맵 (Technical Debt & Roadmap)

## 현재 관리 중인 항목
1. **토큰 쿼터 API 공식 키 연동**:
   - 현재 로컬 SQLite 및 세션 로그 파싱 방식으로 100% 동작 중이나, 사용자가 직접 OpenAI / Anthropic 관리자 API 키를 입력할 경우 공식 사용량 엔드포인트와 하이브리드로 병합하는 기능 구현 예정.
2. **원클릭 하네스 업그레이더**:
   - 기존에 하네스가 50점 이하인 구형 프로젝트에 원클릭으로 5계층 문서를 최신 규격으로 업그레이드해주는 CLI 커맨드 고도화.
